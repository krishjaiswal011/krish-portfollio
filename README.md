# Krish Kumar Jaiswal - Personal Developer Portfolio

An ultra-modern, high-performance, responsive personal portfolio website built with clean HTML5, CSS3 (Glassmorphism & Cyber-glow design system), and vanilla JavaScript.

## 🚀 Key Features

- 🌓 **Dark / Light Mode**: Seamless theme switcher with persistent storage and system theme detection.
- ⚡ **Dynamic Typewriter & Constellation Canvas**: Ambient particle background with mouse repulsion physics.
- 🫀 **Interactive ECG Waveform Simulator**: Real-time canvas medical monitor visualization with pulsing BPM counter.
- 🧠 **Interactive AI Focus & Addiction Risk Engine**: Live calculation widget for screen time vs. study duration metrics.
- 💼 **Resume Modal & Print Preview**: Integrated printable and clean printable-ready CV preview.
- 🛠️ **Categorized Skills Matrix**: Filter tabs for Languages, Web & Tech, Databases & Tools, and Core Domains.
- 🏆 **Achievements & Certifications Shelf**: Highlighted LeetCode 100-Day Badge, Hackathon Top 10 rank, and OpenAI Bootcamp credentials.
- 📬 **Interactive Contact Form & Quick Copy**: Instant copy buttons for Email (`krishjaiswal1314@gmail.com`) and Mobile (`+91 7209810196`) with toast feedback.

## 💻 How to Run Locally

You can open `index.html` directly in any web browser, or serve it using Python or Node:

### Option 1: Double-click
Simply double click `index.html` in your file explorer.

### Option 2: Python HTTP Server
```bash
cd /Users/krishkumarjaiswal/.gemini/antigravity/scratch/krish-portfolio
python3 -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## 🌐 Free 1-Click Deployment

### GitHub Pages
1. Push this folder to a GitHub repository named `portfolio` or `krishjaiswal011.github.io`.
2. Go to **Settings > Pages** and select `main` branch root (`/`).
3. Your site will be live at `https://krishjaiswal011.github.io/`!

### Vercel / Netlify
Drag and drop this folder onto [Vercel](https://vercel.com) or [Netlify](https://netlify.com) for instant global deployment.
